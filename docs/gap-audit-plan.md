## 2. 원인 파악 도구 — 만들 것

**A. 설명 도구 `scripts/explain.mjs <사업장 no | 이름>`**
한 기록에 대해 모든 근거 층을 한 번에 출력한다.
- 정보몽땅 원자료: 단계·대표지번·지도코드
- 구역 연결: 방법(map/point/name/parcel/special), 폴리곤 이름·면적·고시일, dupOf 여부
- 서울주택정보마당: 착공 목록·이주완료 목록 매칭 결과와 점수(`bestHousingMatch`)
- 건축물대장: 법정동 총괄표제부 후보 행마다 (사용승인일·세대·대지면적·지오코딩 거리) 와 어느 조건에서 걸러졌는지
- V-World 건물 신호: tall·n, 캐시 키
- 최종: 앱이 계산하는 stage 문자열 → stageGroup → phase → zoneStatus, 그리고 **어느 규칙이 결정했는지**
캐시(data/raw/*.json)만 읽어 네트워크 없이 돌게 하고, 필요하면 `--fetch` 로 다시 조회.

**B. 정답 목록 `data/truth.json` + `npm run audit`**
사용자가 확인한 현실을 적고, 빌드 끝(또는 단독 실행)에 앱 분류와 비교해 위반을 출력하는 회귀 검사.
초기 항목(2026-09-08 확인):
- 준공: 동작1(이수스위첸포레힐즈), 개포주공1(디에이치퍼스티어아이파크), 반포3주구(래미안 트리니원), 장위4(장위자이레디언트), 홍은13(서대문 센트럴아이파크), 신사1(두산위브트레지움), 역촌1
- 옛 기록: 반포경남(→ 신반포3차·경남)
- 진행: 신반포4차(조합설립), 미아3구역(2027 착공 예정), 도환중1(착공 2024), 오전나(착공 2022), 공덕1(착공 2023), 마포로3-3(2027 입주), 반포주공1단지 1·2·4주구, 신반포12차·16차·27차(관리처분)
정답 스키마: `{ no, name, truth: "완공"|"진행"|"옛기록", note, checkedAt }`.

**C. 표본 감사**
후기 단계 125건(서울) 중 무작위 20건을 뉴스·지도로 사람이 확인해 정답에 추가 → 규칙별(doneBy·built·useApr) 정확도를 숫자로 낸다. 초기 단계 400여 건은 건물 판별 오탐 100% 였으므로 후기에 집중.

**D. 라벨·배지 정리**
보정 표시가 있으면 라벨과 배지에 **보정 결과를 먼저** ("준공 2026-03 · 원자료 착공"), 원자료 단계는 패널 상세에만. `MapApp.descOf`, `DetailPanel` 배지, `shortLabel` 둘째 항목.

**E. 점과 폴리곤 안내**
- 범례에 "● 점 = 경계 자료가 없는 사업장(모아타운·소규모·경기·인천 대부분), ▱ 폴리곤 = 정비구역·필지·특별계획구역 경계" 설명 줄
- 모아타운·`locSrc:"emd"` 마커에 '대략 위치' 표시(점선 원 또는 툴팁), 경계 폴리곤 안에 찍힌 점은 폴리곤 바깥으로 살짝 밀지 않고 그대로 두되 툴팁에 "인접 구역과 별개 사업" 안내
