# 후기 단계 표본 감사 (2026-09-08 추출)

`node scripts/audit.mjs --sample 20 --seed 20260908` 로 뽑은 서울 후기 단계(관리처분~분양, 완공 보정 안 된) 표본 20건.
사람이 뉴스·지도로 현실을 확인해 **현실(기입)** 열에 `완공` / `진행` / `옛기록` 을 적고, 확인한 것은 `data/truth.json` 에
`{ "no", "name", "truth", "note", "checkedAt" }` 로 옮긴다. 원인을 짚을 때는 `node scripts/explain.mjs <no>`.

- 표본 모집단은 `explainStage(p).phase === "후기"` 인 서울 기록(2026-09-08 기준 105건, 이미 정답에 있는 것 제외).
- 확인이 끝나면 `npm run audit` 이 규칙별(useApr·built·doneBy·stale) 적중/오탐과 놓친 준공을 집계한다.
- 같은 seed 로 다시 뽑으면 같은 표본이 나온다(정답에 추가된 기록은 빠지므로 다음 표본은 seed 를 바꾼다).
